Simple Music Player 本地音乐播放器
Alpha 0.3 · 早期测试版（Windows x64）
====================================================

【重要】

这是 Alpha 0.3 早期测试版本，功能和界面仍在快速调整，
可能存在崩溃、播放异常、界面错位或配置不兼容等问题。

- 试用或升级前，请先备份程序目录下的 config 和 data 文件夹。
- 不要把它作为唯一副本用于重要场景。
- 遇到问题欢迎到 GitHub Issues 反馈。

【运行】

1. 把整个压缩包解压到任意文件夹，不要只把 Music.exe 单独拖出来。
2. 双击 Music.exe 直接启动，不需要任何启动脚本，也不会先解压运行时。
3. 请保持文件夹内的 DLL、Assets、en-us、zh-CN、language、Microsoft.UI.Xaml
   等文件和文件夹与 Music.exe 放在一起，它们都是运行必需的。

【本次新增】

- 收藏的项目：侧栏新增入口，所有点过收藏的歌曲集中显示；曲目行、播放页、播放条都能收藏。
- 播放顺序：默认列表和自定义列表按各自列表顺序播到底；最近播放和收藏点播只播一首。
- 文字滚动：标题过长时自动横向滚动，无缝循环。
- 右键菜单：播放条、播放页、最近项目都能右键，与曲目行共用同一套菜单。
- 播放列表菜单：新增“添加到播放列表”和“添加到新播放列表”。
- 设置页：新增“新建播放列表时提示命名”；主题选项支持英文。
- 修复：循环按钮不显示、搜索框按空格误暂停音乐、切换语言后显示“未播放”等问题。

【文件说明】

- Music.exe            主程序，直接双击启动
- *.dll                运行库（.NET 10 与 Windows App SDK），不可删除
- Assets\              图标
- config\              首次使用后生成：播放队列、最近播放、自定义播放列表、界面设置
- data\tracks\         每首曲目的导入时间、文件参数和元数据
- logs\                启动异常日志

【提示】

- 播放列表、界面主题和语言保存在 config 文件夹，删除程序前可先备份。
- 程序未做代码签名，Windows SmartScreen 提示时选择“更多信息 → 仍要运行”。
- 更换电脑时请复制整个文件夹，只复制 Music.exe 无法运行。

【快捷键】

Ctrl + O      导入音乐
Ctrl + F      聚焦全局搜索框
Space         播放 / 暂停
Alt + Left    从全窗口播放页返回
Esc           在搜索框中清空搜索并返回原页面
双击曲目      播放该曲目
